# nirish

niri+ish -> niri as the window manager with the last of the my initials.

# Configuration files

This config is for `niri` which is a standalone config with other related
applications.

## Packages required for noctalia to work

1. `wlsunset` - required for night light functionality
2. `swaylock-effects` - Swaylock utility for for locking screen with eye candy
3. `awww` - drawing wallpaper on screen
4. `waybar` - a must have status bar
5. `cliphist` - used for having history of things copied to clipboard
6. `bluetui` - TUI for managing bluetooth devices and settings
7. `mako` - notification daemon for notifications used by some applications
8. `wtype` - used to auto insert emoji from `rofimoji`
9. `rofi` - application launcher
10. `rofimoji` - emoji selector for rofi
11. `xdg-desktop-portal-gtk` & `xdg-desktop-portal-gnome` - gnome one is needed
    for screencasting and screenrecording menu
12. `gpu-screen-recorder` - used to record screen with audio support
13. `wifitui` - TUI for managing wifi devices and settings related to network
14. `pavucontrol` - used for managing audio devices
